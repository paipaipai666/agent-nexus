# TUI 单栏与运行状态

日期：2026-10-19。基线：dbbf9a4。用户已确认单栏效果图、HUD 分隔线与运行状态，并授权实施。

## 目标

界面跟随终端默认前景、背景和基础色。请求、思考、工具与回答通过提示符、缩进和间距区分。思考默认展开，与主记录共用滚动。日常底部固定三行：分隔线、输入、状态与操作。

运行状态优先显示空闲、工作中及当前动作、等待回复或状态不可用。动画只表达实际运行，不通过静默时长推断状态。子任务尚未结束、取消尚未完成或其他并行工具仍在运行时，不显示空闲。

## 非目标

不增加双栏或侧栏，不更换 Textual，不修改模型协议、数据库格式、工具权限或桌面端。沿用现有操作定义、业务命令、草稿和送达确认机制。无色模式仍保留状态文字和选择标记。

## 受影响区域

TUI 的活动状态、输入与 HUD、事件呈现、主题、记录样式和单栏任务页，以及对应的实际键盘流程测试、预览和打包检查。

验证沿用已有边界：从真实 Textual 按键提交任务，通过 ChatService 事件和任务结果核对显示；通过界面选择、复制、展开和返回核对交互。状态组合计算另用固定业务样例验证，不以私有处理器调用代替完整流程。

## 提交与验证顺序

1. `feat(tui): show live session activity in the status bar`。从真实运行事件、确认请求和协作状态生成当前活动，验证启动、思考、并行工具、切换会话、取消、等待与失败。
2. `refactor(tui): simplify the terminal workspace and composer`。移除常驻配置按钮排，固定输入与记录两个区域；HUD 加分隔线与自适应摘要，任务详情统一单栏，保留全部快捷键和鼠标入口。
3. `feat(tui): follow terminal colors and refine transcript presentation`。默认 ANSI 配色与无色模式，统一正文层次，移除思考内部滚动，检查深浅终端、窄屏、菜单、长内容与安装包。提交包含对应测试与文档。

各单元先验证再推进。最终运行 TUI 功能对齐套件、Ruff、无注释门禁与打包后离线操作。实际终端的输入法、宿主截获按键与配色响应需与自动验证分开记录。
