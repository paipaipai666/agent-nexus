# 准备知识库模型

桌面安装包不包含模型权重。默认嵌入模型首次下载约 92 MiB，可选排序模型约 2.14 GiB。

## 首次使用

1. 联网后，打开 **Settings → Knowledge** 并上传文档。首次上传会下载嵌入模型。
2. 等待摄入完成，再搜索文档。下载时长取决于网络，页面显示当前阶段。
3. 如需重排序，点击 **Download model**。排序模型未就绪时，搜索使用混合检索，结果会显示该模式。

若下载失败，检查网络和磁盘空间。在模型提示处点击 **Retry preparation**，然后重新上传摄入失败的文档。旧索引需要重建时，页面提供准备入口。

## 提前准备离线使用

如果使用命令行，在联网时运行：

```bash
nexus kb prepare
```

如果还需要排序模型，运行：

```bash
nexus kb prepare --reranker
```

完成准备后，可以断网并继续使用已缓存的模型。缺少嵌入模型时，离线摄入会明确失败，不会写入散列回退向量。

默认模型保存在 `HF_HUB_CACHE/agentnexus/<模型仓库>/<固定版本>` 下。已有完整 Hugging Face 缓存也可复用。迁移到离线机器时，同时保留模型缓存和 AgentNexus 的应用数据。

若设置了 `HF_HUB_OFFLINE=1` 或 `TRANSFORMERS_OFFLINE=1`，先取消该设置再准备缺失的模型。
