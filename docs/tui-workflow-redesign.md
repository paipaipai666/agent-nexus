# TUI 操作流程重构

2026-10-19，用户授权较大范围调整，不再沿用其他产品的布局，并要求显示代理思考内容及合理拆分提交。

## 目标

主对话按发生顺序显示模型实际返回的思考、工具和回答。思考默认可见，支持折叠和全文阅读。将功能入口从命令列表转为可选择的操作，输入参数有独立提示。统一任务详情，输入可在当前会话内编辑多行。

## 非目标

不调整代理推理策略、数据库结构和共享服务协议。不合成未返回的思考内容。不修改已有 Electron 构建产物或评估方案。

## 影响模块

`agentnexus/tui/` 的执行事件适配、历史恢复、导航、输入和样式；Textual Pilot 回归；预览及打包验证脚本；终端使用说明。

## 回滚

三个提交分别保留可运行、已验证的状态。按相反顺序撤回提交即可恢复原操作方式，用户会话和附件数据不做迁移。

## 提交单元

1. `fix(tui): show reasoning in the conversation timeline`：思考块、流式顺序、历史标记、运行中切换恢复。
2. `feat(tui): guide terminal actions through contextual pickers`：模型、思考强度、附件和恢复的交互入口，统一任务详情，参数表单。
3. `feat(tui): unify inline composition and terminal layout`：内联多行编辑、明确排队状态、减少重复信息、窄屏与主题验证。

每步先添加实际交互失败用例，再实现并运行相关回归。测试入口沿用已确认的应用启动、按键、显示结果及会话持久化。最终运行功能对齐验证、注释门禁、Ruff、安装包启动，并导出实际应用画面。

## 验证记录

第一单元：新用例先因缺少思考组件失败，实现后，工作区、共享执行、聊天、生命周期与消息测试合计 129 项通过。覆盖流式思考可见、思考与工具顺序、折叠及全文、历史标记恢复、运行中切换会话。流式思考按 50ms 合并刷新，不为每个 token 重建任务面板。

第二单元：模型与思考选项、附件表单、资料检索入口、任务恢复和全部命令纳入操作菜单。参数表单保留原消息；任务页统一展示 Todo 与子代理。先验证旧实现不能打开思考选择器、附件表单及宽屏任务页，再完成实现。功能对齐相关 409 项测试通过，Ruff、注释门禁及差异空白检查通过。

第三单元：输入改为单一 TextArea 缓冲区，内联增高，F4 切换模式、Ctrl+S 统一发送。中文及 LF、CRLF、CR 粘贴不重复、不自动发送；会话草稿继续使用原存储。删除原单行输入与弹窗之间的转交逻辑。为输入区提供模型、思考、计划和附件入口，长模型名在 60 列终端自动让出操作空间。任务栏优先显示待答复和排队数量；读取任务状态失败显示错误并保留界面。

最终功能对齐验证 409 项通过、3853 项不在本次筛选范围。Ruff、注释门禁、差异空白检查通过。最终 wheel SHA256 为 `ff5c1320a2a9ccc7971b2eed2e05e7fe3872e84a07907aedf5c44779c5fe03fa`，从独立安装目录启动后，80×24 欢迎页、操作选择、内联多行编辑和统一任务页通过。实际 Textual 界面已导出并检查 80×24、100×30、浅色主题。预览数据在临时目录运行，不请求模型。

本轮验证还发现两处使用问题并补回归：已发送的文件草稿会重新填入编辑区，现改为提交时消耗；长模型名称会挤出附件按钮，现改为剩余宽度布局。测试等待实际流式内容刷新与按钮可点击状态，不依赖任意固定休眠。
