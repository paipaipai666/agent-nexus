# 终端界面实施记录

用户于 2026-10-17 确认按字符 Logo 欢迎页与 AgentNexus 特征版任务流实施。

## 目标

默认单列对话，使用项目 Logo 的块字符版本作为新会话欢迎区。首条用户输入后收起欢迎区，恢复历史会话直接显示历史。工具默认摘要、按需展开。协作树展示真实子代理和待回答问题，支持直接回复。输入提供附件提示、F4 多行编辑、命令选择和会话选择。窄屏通过独立视图访问详情，宽屏允许手动展开侧栏。

## 非目标

保持上一阶段共享聊天、队列、取消、恢复和持久化语义。不修改代理推理策略、HTTP 协议或数据库结构。不使用示例来源数、任务进度或完成状态。不修改已有 Electron 构建产物或评估改进方案。

## 影响模块

`agentnexus/tui/` 的应用主题、聊天视图、输入、消息、HUD 与新交互组件；`scripts/verify_tui_parity.py` 改为验证已批准的新布局；相关 Pilot 与组件测试；终端命令使用文档。现有 Textual 8 依赖足以支持实现。

## 回滚

实施前将功能对齐后的 TUI 源码、相关测试和打包配置保存至本地 `.research_tmp/tui-functional-baseline.zip`。回滚仅恢复界面源码与测试，不触碰用户配置、会话、知识库与运行记录。上一阶段功能修改继续保留。

## 验证单元

1. 字符 Logo、空会话欢迎区、历史恢复与默认单列，使用 80×24 Pilot 验收。
2. 可展开工具结果、Markdown 回复、阅读时暂停自动跟随。
3. F4 多行编辑与多行粘贴、Ctrl+P 命令选择、F2 会话选择、附件提示。
4. 真实协作树、问题回复、收发回执与 F3 按需详情；运行和任务记录。
5. 80×24、100×30、120×32 与窗口缩放；相关 Python 测试、desktop Vitest、lint、注释门禁、打包启动。

测试入口沿用功能阶段已采用的公共交互入口：实际应用、按键与输入、显示结果和持久化会话，不以私有方法调用作为新增行为的验收标准。
