# 失败恢复修复与验证

本轮处理此前列出的 14 项问题。故障测试使用临时数据库、模拟模型与连接，不调用真实模型，也不写入用户的会话数据库。断线立即停止的产品规则保留，检查点恢复仍只改变会话上下文。

| 项目 | 修复后的行为 | 复现与验证 |
| --- | --- | --- |
| 1. 跨会话版本操作 | 状态、历史、撤销、重做、跳转、重置与手动压缩都指定会话，运行中拒绝修改历史 | 双会话真实数据库 HTTP 测试先失败，再验证另一个会话的历史和内存不变 |
| 2. 保存失败误报 | 写入成功才确认保存；数据库写入失败回滚；结果与恢复记录可单独重试；存储初始化互斥，初始化失败后仍可重试 | 磁盘异常、SQLite 检查点触发器、恢复记录写入失败及重复重试测试先失败；并发停止、轮次提交、存储初始化竞争及初始化失败后的重试也先复现再修复 |
| 3. 重连游标串轮次 | 游标绑定任务 ID，新任务重置游标，旧任务事件不修改当前任务 | 两轮任务的重连地址及旧任务迟到事件测试先失败 |
| 4. 恢复失败自动新建 | 原会话与草稿留在原页面，明确显示恢复错误并原地重试 | HTTP 404 与页面恢复失败测试先失败 |
| 5. 发送等待无期限 | 区分等待连接、等待回执与执行中；等待有时限，原文和附件保留 | 离线发送与超时测试先失败；增加浏览器验收 |
| 6. 重试重复执行 | 稳定提交 ID，在执行前记录接收回执，重复提交及重启后的重复提交返回原任务 | 同一提交只执行一次、同 ID 不同内容拒绝的测试先失败 |
| 7. 连接状态失真 | 显示实际连接状态，传输错误独立于任务失败；断开后查询任务状态 | 连接错误事件测试先失败；增加浏览器验收 |
| 8. 恢复结果信息丢失 | 保留状态、停止原因、答案、活动与保存状态；重开后可读取记录；完整答案替换半截文本 | 终止事件、重启读取、页面重开、停止后活动及完整答案恢复测试先失败 |
| 9. 停止缺少确认 | 支持取消未发送请求；按提交 ID 停止未确认请求；停止回执与真正结束分开 | 无任务 ID 时取消、后端开始前停止及并发写入测试先失败 |
| 10. 工具确认无回执 | 请求 ID、任务 ID 与过期时间绑定确认；等回执后收起，过期禁用 | 错误确认 ID 拒绝、匹配回复接受和前端等待回执测试先失败 |
| 11. 错误缺少下一步 | 保留 HTTP 状态、错误码和等待时间；限制请求等待；模型、连接、存储故障提供相应动作 | HTTP 限流、超时和任务超时恢复建议测试先失败 |
| 12. 恢复范围与重做丢失 | 明示会话与工作区的恢复范围；重做路径持久化，新分支与删除会话清除对应路径 | 重启重做、分支切换和删除会话的测试先失败 |
| 13. 加载失败像空数据 | 辅助面板显示失败及旧数据更新时间，可单独重试；子任务过程失败不冒充未找到 | 待办与子任务页面加载失败测试先失败 |
| 14. 后端启动与退出 | 启动失败可重试、重启与复制诊断；运行时断开保留当前页面；并发重启共用一次操作 | 启动失败缺少恢复按钮的测试先失败；后端恢复并发、健康进程保留与草稿保留测试通过 |

可重复运行的验证入口：

```powershell
rtk proxy node desktop/scripts/verify-failure-recovery.mjs --unit-only
rtk proxy node desktop/scripts/verify-failure-recovery.mjs
```

每次验证在 `.tmp_pytest/recovery-proof-*` 内输出检查日志、测试报告及构建产物。完整验证还运行新的故障浏览器用例和既有日常交互验收。浏览器用例注入 HTTP 与 WebSocket 故障；真实后端路由和数据库行为由 Python 集成测试覆盖。

浏览器验收还复现了 StrictMode 重新挂载后自动滚动失效的问题：取消动画帧时未清空帧 ID，后续更新一直跳过滚动安排。清理帧状态后，长文自动跟随、阅读历史时保持位置和回到最新输出的验收通过。滚动用例同时更新为先接收任务开始回执，并使用对应任务 ID 与事件序号。

2026-10-13 完整验证通过：前端 224 项、后端 226 项、Chromium 浏览器 30 项。TypeScript、无注释门禁、Python lint、前端构建与 Electron 打包检查均通过。日志与截图位于 `.tmp_pytest/recovery-proof-xjvN7u/`，最终报告为该目录下的 `verification.json`。

后端测试 `test_confirm_bridge_sends_confirm_request` 报告一条 `AsyncMock` 协程在事件循环清理时未等待的警告；本轮未处理该测试清理警告。

验证只覆盖故障注入、真实路由与临时数据库，以及 Electron 生命周期单元测试和构建；未验收安装包中真实后端进程的启动与退出，也未调用真实模型。
